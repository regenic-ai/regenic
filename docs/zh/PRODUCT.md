# 产品定位

- **English:** [../en/PRODUCT.md](../en/PRODUCT.md)
- **相关：** [ROADMAP.md](ROADMAP.md) · [个人 → 组织](rfcs/personal-to-org.md) · RFC 0001–0007

## 1. Regenic 是什么

Regenic 是面向个人与企业的**信息加工层**。

它**不生产**一手信息（聊天、工单、邮件、文档、指标）。
它**接入**信息（push 或 pull），再**加工**信息，使人与 Agent 能在统一标准与
统一上下文下判断与行动。

加工包括（非穷尽）：

| 阶段 | 含义 |
| --- | --- |
| 接入 | 连接器：webhook 推送、轮询拉取、文件导入、Agent 回合 |
| 过滤 | 降噪；遵守 ACL / 个人边界 |
| 分层 | 耐久与敏感分层（Event / Blob / Digest / Standard） |
| 提炼事实 | Claim、Digest、「该知道的」— 须有证据 |
| 迭代标准 | 缺口 → 提案 → 版本化判断标准（RFC 0001） |
| 行动 / 跟进 | 队列、Handoff、未回复线程 — 加工的**应用面** |

收件箱分拣、「该知道」、未回复排序是这条管道上的**表面**，不是产品定义本身。

## 2. 双能力模型

来自《重写基因》：

1. **判断标准** — 编码 / 应用 / 修订共用标准  
2. **统一上下文** — 同一决策同一事实集，带出处  

Regenic 把渠道流量加工为这两项能力的输入。

## 3. 交付顺序：个人 → 组织

| 版本 | 范围 |
| --- | --- |
| **个人（当前）** | 单一 principal；本地优先加工 |
| **组织（其后）** | 跨人的 canonical 事件 + 投影 |

先交付个人版，跑通单人闭环；组织版复用同一对象模型，叠加身份、策略与多人认同
（见 [个人 → 组织](rfcs/personal-to-org.md)）。

## 4. 个人原则

1. **本地权威** — 设备或自托管库为真相源。  
2. **可选远程历史** — 用户可控的冷副本；默认关；不是组织库。  
3. **开放导出** — Markdown / JSON(L)；数据可带走。  
4. **可插拔接入** — ChannelConnector，push 与 pull 同等。  
5. **不是笔记产品** — Phase 1 内核不做 Outliner / 双向链接笔记图谱。

## 5. 近期非目标

- 替换飞书 / Slack / 邮件作为消息传输层  
- 做成通用知识库或文档套件  
- 通用 ERP 模块  
- 未经组织蒸馏，把个人 AI 标签当成组织真理
