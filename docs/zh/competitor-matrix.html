结论：仍无完整撞方；但 2026 新品把 Phase 1 外壳挤热了

没人同时做「多渠道加工 + 版本化判断标准 + 个人权威→组织合并（蒸馏不抬权）」。真正抬升的威胁是：Persnally / Memoreei / Heirloom 把「本地上下文 / 渠道记忆 / 个人→团队」讲清楚了——若对外只讲 memory，会被当成同类。

竞品总表

产品 威胁 定位 重叠 缺口（相对 Regenic） 何时

2026 新出现 / 新升温（优先盯）

A Persnally

本地 context engine，claim 带证据，MCP，纠错权威。2026-07 已加 per-client identity token。最接近「个人双能力」里「上下文」半边，但主线是身份/偏好模型。

A Memoreei

WhatsApp / Discord / Slack / Gmail 等 13 源 → 本地 SQLite → MCP 检索。Phase 1「接真实渠道」演示层最近；缺标准与分层加工。

A Heirloom

2026-05 起；Slack / Obsidian 等 ingest + 已宣称 self-host Teams。唯一把「个人 memory → 组织共享」写进路线的新品，但仍是密文共享记忆，不是权威事件 + 标准。

B Beever Atlas / OpenMemory / Supermemory

Atlas（2026-04）：团队聊天→Wiki。OpenMemory：自托管认知记忆 + 连接器。Supermemory：云端 memory 品类领导者。三者都会抢「context / memory layer」心智。
